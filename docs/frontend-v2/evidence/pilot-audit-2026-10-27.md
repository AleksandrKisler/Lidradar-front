## CSS: измеренная причина и предел оптимизации

Vite experiment использует исходный vite.config и runtime, но через временный
pre-transform меняет только Tailwind source declarations; output в /tmp.
Файлы src не изменялись. `source(none)` + src + index.html:

| Метрика            | Исходно  | Scoped sources                |
| ------------------ | -------- | ----------------------------- |
| Production CSS raw | 53220 B  | 47787 B                       |
| Весь JavaScript    | 816822 B | 816822 B                      |
| Initial JS graph   | 269433 B | 269433 B                      |
| CSS budget         | FAIL     | FAIL, ещё 6787 B сверх лимита |

Отдельный Tailwind compiler/scanner experiment дал 51819 → 46489 B
(это **не** полный Vite CSS). Добавление одного `public/figma-reference.html`
к runtime candidates воспроизводит все 5330 B разницы этого отдельного опыта.
Вклады файлов перекрываются, суммировать их нельзя. Эксперимент устанавливает
ненужную генерацию, но не доказывает отсутствие визуальных регрессий после
ограничения sources — их должен проверить Claude, включая legal pages.

Механизм явных sources описан в [официальной документации Tailwind](https://tailwindcss.com/docs/detecting-classes-in-source-files).
Baseline HEAD 41913 B — прежнее измерение Claude, в этом аудите не пересобирался.

## Реальные зависимости и решения

`RadarAction`/`RadarOutcome` не возвращают note; рабочие минуты и threshold также
не являются полями RiskDetail. Их нельзя восполнить вёрсткой. При этом отсутствие
счётчиков не мешает вкладкам без чисел; отсутствие города не мешает показывать
число точек; нет оснований блокировать пилот выбором акцентного detail или F03.
Состояние Telegram надо выводить по liveConnections с проверкой права, не по
личному telegramLinked. Денежные подписи/агрегирование сохраняются.

В отчёте Claude неверно указан US-M07-03 шаг 4: этот story про своевременный
ответ, у него всего 3 шага. Требования старой карточки находятся в US-M07-01 шаг 4.
UI v2 mapping и решения по disabled/копии зафиксированы в задании; канонические
backend stories не изменены и старые буквальные шаги не объявлены выполненными.
