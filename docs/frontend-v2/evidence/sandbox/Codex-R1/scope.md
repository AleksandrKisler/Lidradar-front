# Песочница · 31.10.2026

Поручение владельца: перенести эмулятор переписки в дизайн текущего приложения
и сделать доступным на stage и localhost. Уточнение: **production исключён**.
Backend, ADR 0066, контракт, лимиты и Figma не меняются.

## Проверяемый scope

- SB-01 / US-M17-01,06: `/sandbox` в общей оболочке; меню только при
  `sandbox: true` из `/auth/me` и `conversation.read`. Без флага нет sandbox API
  запросов; прямой адрес показывает недоступность. Владелец и менеджер допустимы.
- SB-02 / US-M17-02: квалифицированные шаблоны, точка, имя, состав сообщений,
  пауза и давность, удаление; Enter не отправляет сообщение. Черновик сохраняется
  в браузере с изоляцией user/tenant. Ошибки хранения показаны явно.
- SB-03 / US-M17-03,04,05: POST сборки и последующих сообщений через настоящий
  sandbox API; список обновляется каждые 5 секунд; выбранная переписка в PROCESSING
  опрашивается отдельным GET каждые 3 секунды по контракту. Показаны реальные
  состояния/этап/срок проверки, найденные риски и переход в Диалоги.
- SB-04 / US-M17-07: ошибки команд и чтения, повторы с неизменными key/body,
  сохранение незавершённой команды при reload; ограничения истории/состава.
- SB-05: Inter и существующие семантические tokens/primitives; адаптивы
  1440/834/390/320, отсутствие горизонтального скролла.
- SB-06: прежние gates, бюджеты, backend/API, package-lock и evidence сохранены.

Локальный запуск: Node из `.nvmrc`, `npm run dev:stage`, адрес
`http://127.0.0.1:5173/sandbox` (также доступен через localhost, если он разрешается
в 127.0.0.1). Vite использует существующий stage proxy; нужны уже настроенные
серверные stage credentials и вход пользователя в тестовую организацию.
`npm run dev` с backend на 8081 сам по себе не включает серверную песочницу:
ADR 0066 разрешает её только staging backend. Localhost использует stage API.
Production не включается никакой frontend-настройкой.

## Визуальное основание

Approved-pattern: DESIGN.md, runtime main.css и UiCard/UiField/UiButton,
действующая оболочка C из `radar.shellSelection` в design-index.json.
У песочницы нет утверждённого v2 exact-frame: старый M3 HTML-прототип
используется только для понимания сценариев. Нельзя заявлять pixel-perfect
сравнение с отсутствующим Figma-экраном. Figma/access/onboarding не менялись.

## Предел приёмки

Frontend/mock проверки не доказывают реальный AI pipeline, доставку, наступление
и закрытие рисков на stage. Полные US-M17-01–07 требуют отдельного живого QA.
Отображение времени сообщений — подтверждённое серверное; draft-предпросмотр
абсолютного времени и расширенная диагностика AI не входят в этот перенос.
