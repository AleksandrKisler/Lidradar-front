# Зависимости пилота от API и дизайна

## Действующий релизный контур — 27.10.2026

Применять [RELEASE-SCOPE.md](RELEASE-SCOPE.md). Пользователь отложил расширение
стабильного backend до большого обновления после релиза. Отсутствующие timing,
счётчики по статусам/HIGH, чтение заметок/всех исходов и чтение оплат сделки
не являются prerequisite текущего frontend; интерфейс использует согласованные
ограничения и не обещает эти возможности.

Действуют: абсолютные dueAt/detectedAt; вкладки без чисел с группой
ACKNOWLEDGED+ACTED; существующая денежная сводка за всё время; действия,
этапы и отдельно последний исход; безопасный повтор оплаты прежними key/body.
liveConnections не доказывает исправность Telegram. Зелёный статус по нему
не показывать. Прошлые BLOCKED/DECISION_REQUIRED в таблице ниже — история
проверки и не переопределяют текущий релизный контур.

## Актуальные решения пилота — 27.10.2026 (PILOT-ACCEPTANCE-TASK)

Решения приняты заданием [PILOT-ACCEPTANCE-TASK.md](PILOT-ACCEPTANCE-TASK.md) и реализованы
в коде; это условия реализации пилота, G01 они не принимают. Доказательства —
[audit](evidence/pilot-audit-2026-10-27.md) и [acceptance-mapping](evidence/F02/acceptance-mapping.md).
