# Фиксация макетов Доступа до фактического релиза

Актуальное уточнение владельца от **01.11.2026**: под заморозку должны
попадать **только экраны Доступа**. Настройки и Аналитика в неё не входят.
Прежние ограничения Онбординга и Radar также сняты этой формулировкой.
Это решение заменяет область первоначального решения от 30.10.2026.

Плановый релиз — **01.11.2026**. Для Доступа фиксация действует до фактического
выпуска либо нового решения владельца; календарная дата сама по себе её не отменяет.

## Актуальная область

| Область                                  | Режим                                                    |
| ---------------------------------------- | -------------------------------------------------------- |
| Доступ                                   | Макеты зафиксированы, правки макетов запрещены.          |
| Настройки, Аналитика и остальные разделы | Вне заморозки, обычный процесс изменения и согласования. |

Для Доступа запрет включает компоновку, навигацию, визуальные элементы,
тексты, состояния, адаптивы и визуальные пользовательские пути. Новые
варианты и замена утверждённых эталонов требуют нового решения владельца.

Режим распространяется на косвенные изменения Доступа через общие Figma
components, masters, styles, variables и tokens. Работа в остальных разделах
должна сохранять зафиксированные экраны Доступа: общие изменения изолировать,
если они затрагивают этот эталон.

## Работа и источники

Для Доступа использовать утверждённые узлы `access` из
[design-index.json](design-index.json). Для остальных разделов использовать
их текущие утверждённые источники и обычный процесс: макеты → согласование
владельцем → дальнейшее поручение по реализации. Наличие незамороженного
раздела не запускает разработку автоматически и не присваивает runtime PASS.

Реализацию и QA продолжать по текущим утверждённым эталонам. Границы API,
порядок TEST → FUNCTIONAL → UI, release gates и запрет самостоятельных действий
в production сохраняются. Runtime-ограничения экранов Доступа описаны в
[CODE-FREEZE.md](CODE-FREEZE.md).

## История решения

30.10.2026 исходное решение включало Доступ, Онбординг и ограничение крупных
изменений Radar. Исторический [снимок указателей](evidence/design-freeze-2026-10-30/baseline.json)
с SHA-256 трёх областей сохранён без перезаписи. Он не расширяет актуальную
область после уточнения 01.11.2026 и не означает новую приёмку Figma/runtime.

Уточнение R38 и утверждение desktop «Услуги и цены» записаны в STATUS,
`releaseDesignFreeze` и `settingsServicesSelection` в design-index. Figma
настроек и аналитики не должна блокироваться старой областью заморозки.
