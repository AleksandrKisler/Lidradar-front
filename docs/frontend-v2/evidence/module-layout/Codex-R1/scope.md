# Общая оболочка четырёх разделов · Codex R1

Поручение от 31.10.2026: перенести принятую оболочку Radar в «Диалоги»,
«Аналитику», «Интеграции» и «Настройки». Содержание разделов и бизнес-правила
сохраняются. Это продолжение реализации frontend, а не новый дизайн.

Статический CANVAS PASS не заменяет runtime-приёмку.

## Границы визуального сравнения

Проверяется оболочка: sidebar, header, контекст, drawer, активные состояния,
адаптивность и отсутствие перекрытия содержимого. Старое содержимое четырёх
разделов сохраняется: отличия его заголовков, таблиц, карточек и данных от
демонстрационных тел Figma не входят в этот перенос. Новые состояния и прочие
вкладки используют approved shell pattern; exact-frame применяется к drawer.

720×500 CSS viewport моделирует reflow 1440×1000 при 200% zoom, но не является
проверкой нативного масштабирования macOS. Live stage до отдельного запуска
остаётся UNVERIFIED.
