## Разработка и тестирование

Подготовлен [промпт реализации](../prompts/analytics-implementation-2026-11-03.md)
для US-M13-01–04. Текущее поручение — подготовить промпт; runtime-разработка
в этом ходе не начата. Передача этого промпта исполнителю является поручением
на реализацию, повторное согласование уже утверждённых макетов не требуется.

Прямое указание владельца имеет приоритет над общими требованиями WORKFLOW
о финальных полных прогонах для данной задачи:

- разрабатывать и проверять три раздела аналитики и изменённые связи между ними;
- unit/integration/E2E и визуальную проверку ограничить этой работой;
- переход в риск/диалог и возврат проверять только как сценарий аналитики;
- не запускать полную регрессию приложения, общий coverage, все stand-сценарии
  или полную browser matrix; не вызывать широкие обёртки `npm run check` и
  `audit:release`;
- общая итоговая приёмка frontend отложена до завершения его разработки;
- не отключать тесты, assertions, coverage thresholds или CI: область запуска
  сужается выбором конкретных тестов, а не ослаблением проверок;
- при исправлении повторять затронутые проверки; общий PASS приложения
  не заявлять по результатам проверки одной аналитики.

Статические проверки изменённых файлов и необходимый typecheck допустимы;
это не разрешение на полную тестовую регрессию приложения. QA/visual reviewer
получают те же границы и зафиксированный снимок, включая untracked inputs.
