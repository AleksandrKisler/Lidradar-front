В техническом решении отдельно определить хранение черновиков, запись нескольких
недель, восстановление после частичного/неизвестного исхода и согласованность
серверного статуса онбординга. Атомарность недели одной точки не означает общей
транзакции всех точек. Новые API этим отчётом не вводятся; примеры 30/60 в макетах
не меняют серверные defaults 45/120.

Правило переключения онбординга **не переносится в настройки US-M02-06**:
там подтверждение ухода с несохранённым графиком сохраняет отдельный смысл.
