## Итог

После повторной проверки исправлен ритм всех 22 состояний по фактическим размерам утверждённых экранов. Предыдущая проверка шкалы UI Kit не выявила расхождения между индикатором шагов, заголовком и содержимым; одной проверки токенов для этого оказалось недостаточно. Это веб-интерфейс Vue. Из Apple HIG применены принципы читаемости, иерархии, обратной связи и сохранения контекста. Точные размеры и шрифт берутся из UI Kit LidRadar; размеры ниже не объявляются обязательными числами Apple HIG.

## Неверный ввод и переключение точек

1. Переключение точек при неверном вводе **разрешено**. Оно меняет выбранную точку и правую область.
2. Черновик и ошибка принадлежат точке. При возврате восстанавливаются те же значения, например 20:00–09:00.
3. У проблемной точки постоянно видна красная подпись **«График заполнен неверно»**. Обычный статус «График заполнен» допустим только для валидного графика.
4. У текущего некорректного поля остаются красная обводка и пояснение способа исправления.
5. Если выбрана другая корректная точка, ошибка первой продолжает блокировать сохранение всего шага. На телефоне она дополнительно названа под выбором точки, поскольку список скрыт в селекторе.
6. «Сохранить и продолжить» доступно только после исправления ошибок и заполнения обязательных данных всех добавленных точек.

[Некорректный график выбранной точки](https://www.figma.com/design/jN8Hhzn6ObIAEi7FoY9kPu?node-id=879-11515), [другая точка выбрана, ошибка остаётся](https://www.figma.com/design/jN8Hhzn6ObIAEi7FoY9kPu?node-id=895-12679), [тот же случай на планшете](https://www.figma.com/design/jN8Hhzn6ObIAEi7FoY9kPu?node-id=895-12851).

Это решение поведения показано в статических состояниях; рабочая валидация и переключение в приложении этой задачей не реализованы.

Основание: `entering-data.md › Best practices` — «Dynamically validate field values»; `feedback.md › Best practices` — размещать обратную связь рядом с соответствующей информацией и объяснять недоступность действия. Точный текст статуса и разрешение переключения — решение этого продукта.
