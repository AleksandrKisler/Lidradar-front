## Визуальное направление

Спокойный рабочий web-интерфейс. Точное воспроизведение Figma, без переосмысления.
Inter; canvas #F5F5F7, paper #FFFFFF, ink #1D1D1F, muted #6E6E73,
primary #0071E3; семантика риска и денег берётся из соответствующего эталона.
Базовая desktop шкала: 32/40, 20/28, 16/22, 14/20, 12/18.
Адаптивные размеры текста и геометрия — из выбранного фрейма, не механическое
масштабирование desktop. Основные поля и кнопки 46 px; задокументированные
исключения (например compact time) не переносить на все контролы.

## Владелец runtime

Единственная точка runtime-токенов: `src/app/styles/main.css` (@theme).
Общие primitives: `src/shared/ui`; оболочки: `src/app/layouts` + существующие widgets.
Трасса: Figma semantic variable/style → запись в карте этапа → runtime @theme →
shared primitive → экран. Не копировать hex/размеры в каждый экран.
Сейчас CSS использует Roboto Flex/M3: это исходное состояние, не эталон v2.
Первый этап переносит шрифт и общие токены с учётом регрессии всех потребителей.

## Поведение

User stories и действующий API определяют сценарии; Figma определяет визуал.
Неизвестное не равно нулю. Refresh сохраняет подтверждённые данные и черновики.
Skeleton скрывает динамические данные, сохраняет статические подписи.
Busy не меняет размер кнопки. Ошибки локальны операции и допускают повтор.
Навигация, focus и scroll работают при узком окне и длинном контенте.
Контраст, клавиатура и семантика проверяются в браузере.
